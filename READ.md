**Invest Qatar Landing Page**

## Project Overview

This is a responsive UI project created using only HTML, CSS/SCSS, and vanilla JavaScript.
It replicates and improves the provided prototype, focusing on responsiveness, usability, and smooth interactions.

## Installation

1. Clone the repository:

```bash
git clone https://github.com/RamsiyaKA/invest-qatar.git
```

## How to Run Locally

- Download the project ZIP file or clone the Git repository.

- Open index.html in your preferred browser (Chrome, Safari, Firefox, or Edge).

- All interactions and functionality should work out of the box — no build step required.

## Libraries / Plugins Used

- None — all functionality is implemented using plain HTML, CSS, and vanilla JavaScript.
- Used CDN for fonts and icons

## Approach & Notes

- Designed mobile-first and ensured responsiveness across devices.

- Smooth scroll and dropdown interactions implemented using vanilla JavaScript.

- Dropdowns support hover (desktop) and tap toggle (mobile) with proper outside click handling.

- Back-to-top button added for better user experience.

- Clean and modular CSS structure with comments for clarity.

## Trade-offs / Known Limitations

- No CSS frameworks or JS libraries were used to comply with the requirements; all functionality is custom-coded.

- Some advanced animations could be further optimized for performance on very low-end devices.

- Tested on the latest versions of Chrome, Safari, Firefox, and Edge.
